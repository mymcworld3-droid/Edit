# 問道 Edit Studio

《誰讓他修仙的！》角色戰績剪輯台。作品固定為 **9:16 手機直式**，SVG 邏輯畫布為 **1080 × 1920**。陸陽、黃豆豆、雲芝使用自製可重複利用的古風向量剪影，沒有照片、生成圖片、網路立繪或外部 CDN。

## 開啟

下載儲存庫後，直接以瀏覽器開啟 `index.html`。**不需安裝套件，也不需連線。**

若需要以網站開啟，使用 Node.js 22 以上版本：

```sh
npm start
```

開啟終端機顯示的網址，預設為 `http://localhost:3000`。`npm run dev` 同樣可用，`PORT` 環境變數可更改埠號。

Render 使用 Web Service 時：Build Command 填 `npm run check`、Start Command 填 `npm start`。也可把根目錄當作靜態網站來源；沒有建置步驟。儲存庫附的 Actions 只執行檢查，不會自動啟用 GitHub Pages。

## 使用

1. 按播放，預覽約 35 秒的示範作品：境界 → 荒唐日常 → 抽黑轉折 → 真正戰績 → 三人同框。
2. 點「匯入本機音樂」，選擇自己持有的音檔。指定曲目是 **Wannabe — why mona**。檔案只在目前瀏覽器中使用，不會上傳。
3. **音樂起播**設定作品第 0 秒對應的音檔位置。例如起播 12 秒，作品時間 5 秒將播放音檔的第 17 秒。
4. **Drop** 是作品時間中的高潮起點。輸入秒數或拖動黃色 DROP 線，會把 Drop 前後的鏡頭分別等比例縮放，保持總長與鏡頭銜接。
5. 點時間軸可跳轉，拖曳可細看；按 M 可在目前時間加入節拍標記。本機音檔若可解碼，會顯示實際波形。
6. 點左側分鏡，在右側修改字幕、入出點、人物、段落、效果與光色，再按「套用鏡頭」。移動起訖時間即改變先後順序。重疊會被拒絕，留白會明確提示並顯示空白畫面。
7. 編輯自動儲存在目前瀏覽器。可匯出 JSON 備份、在別的裝置匯入；音檔不包含在分鏡檔中。新開頁面須重新匯入音樂。

尚未提供實際音檔，所以 **35 秒及 Drop 16 秒都是示範值，沒有宣稱對過指定歌曲的節拍**。Spotify 連結僅為曲目參考；本專案不會從 Spotify 下載或擷取歌曲。

## 手機比例與錄屏

- 畫布始終維持 **9:16**。桌面置中等比例顯示；手機編輯時，預覽在上方，分鏡與設定排在下方。
- 按「進入錄屏」或 **H** 隱藏標題、時間軸、工具列與設定。畫布以可容納的最大 9:16 尺寸顯示，不拉伸、不裁切字幕。
- 按 **R** 從頭播放，**空白鍵**暫停。H / Esc 返回編輯。
- 可先按全螢幕，再以系統錄屏工具錄製；返回按鈕在游標停止移動後會消失。手機若不是 9:16 螢幕，四周留黑是為了保持正確比例，錄製後可裁成 9:16。
- 這一版提供可錄屏的乾淨畫面，**沒有假稱能一鍵匯出 MP4**。系統音訊錄製方式依裝置與瀏覽器而異。
- 編輯頁切到背景會暫停，避免回來時錯過片段。

| 按鍵 | 功能 |
| --- | --- |
| Space | 播放 / 暫停 |
| R | 從頭播放 |
| ← / → | 上一幕 / 下一幕 |
| M | 在目前時間加入節拍標記 |
| H | 進入 / 離開錄屏模式 |
| Esc | 離開錄屏與全螢幕 |

## 編輯資料與程式

`scenes.js` 是預設作品的單一資料來源，格式為 `window.DEFAULT_PROJECT = { ... }`，方便直接開啟本機 HTML，避免 `file://` 環境禁止 fetch JSON 的限制。UI 匯出的是相同結構的標準 JSON，匯入不執行其中的程式碼。

每幕欄位：

| 欄位 | 說明 |
| --- | --- |
| `id` | 唯一鏡頭 ID |
| `startSec` / `endSec` | 作品時間中的入出點，出點不包含在此幕 |
| `character` | `luyang`、`huang`、`yunzhi`、`trio` 或 `null` |
| `phase` | `intro`、`realm`、`fun`、`break`、`epic`、`final` |
| `text` / `subtext` | 主副字幕；`\n` 換行，主字幕建議一行不超過 8 字 |
| `effect` | 效果 ID，完整表見 `engine.js` 中的 `EFFECTS` |
| `accent` | `#RRGGBB` 光色 |
| `needsVerification` | 是否仍須核對原作 |
| `sourceNote` / `sourceUrl` | 查證備註及來源入口 |

`format.durationSec` 決定總長，`music.musicOffsetSec` 決定起播位置，`music.dropAtSec` 決定 Drop，`beats` 為手動節拍時間。

- `index.html` / `style.css`：編輯台與手機佈局。
- `engine.js`：時間區間、配置驗證、Drop 重定時，無 DOM 依賴。
- `artwork.js`：三人共用 SVG 骨架、場景與特效；根據時間直接計算當前狀態。
- `app.js`：播放、音訊主時鐘、本機草稿、匯入匯出、波形與編輯互動。
- `server.mjs`：選用的零相依 HTTP 伺服器；僅公開所需前端檔案。
- `tests/engine.test.cjs`：時間軸測試。
- `docs/`：原始製作規格、分鏡草案與驗收表。

**同步方式：** 載入音檔且在有效區間內時，以 `audio.currentTime - musicOffsetSec` 作為演出時間；無音樂或音檔已結束時改用可暫停、可跳轉的 `performance.now()` 時鐘。所有畫面以 requestAnimationFrame 更新，特效不依賴一次性 setTimeout 串，也不依賴畫面數。暫停時畫面固定，反向跳轉同樣依當前時間重算。

## 內容查證狀態

這是依使用者提供任務包製作的**含結局劇透之編輯初稿**。原作官方入口：[起點中文網《誰讓他修仙的！》](https://book.qidian.com/info/1036504904/)。本次未取得足以逐幕核實的正版完整章節，**所有涉及小說事實的境界、日常與戰績均保留 `needsVerification: true`**，右側顯示備註。轉場與片名不屬小說戰績，未設待查證。

為避免把草稿誇飾當成事實，做了幾項收斂：

- 「親手終結另一個自己」先改為「對決另一個自己」，結果仍待原作核對。
- 泛稱「鎮壓古仙」改成具名的「不朽仙子初現被雲芝制服」事件，建議核對第 104–105 章。
- 四仙煉化星辰、封鎖世界呈現為黃豆豆遇害的**歷史後果**，沒有畫成她的攻擊。
- 魔教燒烤事業、廚藝與宗門收場的字幕屬濃縮改寫；備註提醒核對歸因。

確認原文章節後，可在 UI 勾選「原作細節已核實」並匯出更新的 JSON。不要僅因看過轉載或二手摘要就把所有標記清除。

## 檢查

```sh
npm run check
```

會檢查四份 JavaScript 語法並執行 Node 內建測試，無需安裝任何套件。測試涵蓋區間邊界、反向跳轉、Drop 重定時、重疊與留白、匯入配置驗證及查證標記。瀏覽器操作驗收結果見 `docs/QA.md`。
