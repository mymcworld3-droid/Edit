# 分鏡、戰績與字幕腳本初稿

> **重點**：這是一支「戰績 Edit」，不是泛泛形容強大。每句要有**做過什麼 + 造成什麼結果**；沒讀過小說的人也能看懂衝擊。以下為可編輯初稿，細節須按原著核對。總長 34–35 秒為假設節奏，實際卡點以使用者合法提供的音檔為準。

## 1. 敘事節奏

### A. 片頭（約 0–5s）先介紹境界

畫面從黑暗展開，像古籍／戰績檔案，三張人物剪影迅速疊現。

- `陸陽`／`劍仙 · 溯源道果`——少年道袍、長劍出鞘的線條。
- `黃豆豆`／`上古五仙 · 不朽道果`——嬌小身影、金色不朽環。
- `雲芝`／`半步合道`——白衣、負手、天地靜止的遠景。

建議片頭字幕：**「先看境界。」** 或 **「境界，是最普通的介紹。」** 字少、停留短。

### B. 不正經戰績（約 5–14s）以幽默吸睛

一條卡 1–1.5 秒；不要每次只有靜止人物站著。

| 人物 | 建議上屏字幕 | 對應畫面／注意事項 |
|---|---|---|
| 陸陽 | **臥底魔教，竟復活了魔教供奉的上古仙子** | 密教符紋→金色仙環炸開；原著情節需核對用詞 |
| 陸陽 | **編出一個天庭教，居然把魔教騙信了** | 假印章、巨大天庭紋樣升起 |
| 陸陽 | **把魔教的事業，做成了燒烤連鎖店** | 小小火焰、招牌輪轉；是偏戲謔文案 |
| 黃豆豆 | **堂堂不朽仙子，復活後住進別人腦海** | 仙環縮小落入陸陽剪影額前 |
| 黃豆豆 | **上古仙人的廚藝，被當成危險源** | 炊煙變成黑色雷雲；表現是喜劇誇飾，細節須核對 |
| 雲芝 | **師父是宗主，卻反被她封印** | 宗主剪影縮成小印，雲芝抬袖 |
| 雲芝 | **整個宗門闖禍，她一人負責收場** | 亂飛的符咒一瞬全部停住；概括性情節，非量化戰績 |

### C. Drop 前轉折（約 14–16s）

前段幽默轉場在半拍內被「抹掉」，環境音抽空、畫面極暗。

字卡：**「但這些——還算不上戰績。」**

另一個備選：**「直到他們認真出手。」**

### D. 高潮（約 16–31s）每一記重拍搭配真正有分量的戰績

| 角色 | 戰績大字 | 給沒看過小說的觀眾的可視化畫面 |
|---|---|---|
| 陸陽 | **凝無敵丹，修成溯源道果** | 劍一分十，十化萬；文字「法術歸源」幾何拆解 |
| 陸陽 | **兩條時間線的終局，都繞不開他** | 兩個持劍剪影分列時空裂縫左右、各自斬向中央 |
| 黃豆豆 | **她的死，讓四位仙人封鎖整個世界** | 先亮起四尊仙影，接著大量星辰合攏成巨大封印盒；不懂「仙人」的人也感到尺度 |
| 黃豆豆 | **四十萬年後，她親手終結另一個自己** | 兩種相反顏色的不朽／寂滅剪影碰撞；涉及灰豆豆大劇透 |
| 雲芝 | **上古仙人現身，仍被她鎮壓** | 古仙巨影壓境，雲芝只抬起一隻手；需核對特定事件 |
| 雲芝 | **半步合道，正面迎戰超脫者** | 遠景中天地大道化為巨環，雲芝剪影微小但鏡頭壓迫感最大；可在劇情層面點出伏胥 |

**重點提示：** 高潮上屏文字要比這份提案更短更利落。可「兩層」呈現：先 8–12 字大字概述，下一拍補 4–8 字結果，例如「她一死」→「四仙封鎖整片星空」。不要讓觀眾在一秒內閱讀 30 個字。

### E. 結尾（約 31–35s）

三人剪影同框：陸陽置中提劍、黃豆豆左側仙環、雲芝右後方白衣。星空崩裂收束為一本古籍，浮出片名。

最後字幕：**《誰讓他修仙的！》**

可選副標：**「別被日常騙了。」**

## 2. 三位角色的風格對比

| | 陸陽 | 黃豆豆 | 雲芝 |
|---|---|---|---|
| 剪影輪廓 | 少年束髮、修長佩劍、短披帶 | 嬌小長髮、飄帶、仙環 | 高挑垂髮、寬袖、長袍、負手 |
| 主色 | 蒼藍、銀白 | 暖金、琥珀 | 月白、冰藍 |
| 前段動作 | 活潑轉身、劍尖挑起符紙 | 好奇探頭、仙環縮小 | 克制皺眉、抬袖收拾 |
| 高潮動作 | 拔劍、萬劍、雙時空斬擊 | 神環展開、星辰封印、雙影碰撞 | 不需大動作，抬眼／伸手令環境靜止 |
| 氣氛 | 少年成長與破局 | 古老而神聖、命運反轉 | 強到無需出招的沉默威壓 |

## 3. 可自行追加／替換的真實戰績方向

- 陸陽：臥底不朽教、編造天庭教、無敵丹、溯源道果、成仙、時間線戰場。
- 黃豆豆：不朽道果、黃豆豆復活、上古四仙的封印、灰豆豆、仙人級不朽能力。
- 雲芝：鎮壓宗門強者／仙人、半步合道、伏胥決戰、守住自我。

**避免：** 將「她一念毀滅全宇宙」「一劍秒殺所有仙人」等未經查證的誇大描述當作原作戰績。也不要把「某事的起因／歷史背景」誤寫成「該角色親手完成的攻擊」。

## 4. 給開發 AI 的剪輯準則

- 時間線是配置而非定時器煙火；同一秒跳轉要立刻看見正確畫面。
- 每個人物的剪影視角與輪廓固定，不能每一幕變成不同長相。
- 先用少量字表現幽默，然後強烈反差進入黑金／冷白壓迫段。
- 高潮字卡逐拍進場，背景的星辰、時間裂縫、仙環要**回應文字的實際內容**。
- 讓沒看過原作的觀眾看懂：封鎖整個世界、四十萬年、兩條時間線、半步合道、迎戰超脫者。
- 這些句子涉及結局大劇透；預設版本允許完整劇透。可加 `spoilerMode` 開關作為進階功能。
